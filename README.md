# 🤲 拊掌游戏 · 线上版

> 一款基于手势的多人实时对战游戏，支持 2-8 人远程在线对局。

变换多端的手势来击败敌人，策略与运气并存。

## 🎮 游戏简介

每位玩家初始拥有 **1 点血量**，通过选择不同招式进行攻击、防御、回血，目标是成为最后的存活者。

### 核心玩法

- **41 种招式**，分为 10 大类别：基础、防御、回血、血攻、挂件、判定、近战、远程、终极、特殊
- **回合制**：所有人同时选择招式 → 揭示 → 结算
- **克制关系**：bird冲 免疫近战并反弹弩/狙击，武装克血祭，反弹克白爆……
- **资源管理**：通过"冲"等技能获取"费"，用来购买更强力的招式
- **团战模式**：多人混战，支持群体伤害、目标指定、分目标攻击

### 特色系统

| 系统 | 说明 |
|------|------|
| 💬 表情互动 | 10 种预设表情，对局中随时挑衅对手 |
| 📋 招式揭示 | 每回合结算前公开展示所有人的招式选择 |
| 🎯 狙击阶段 | 狙击手在揭示后单独选择目标，支持"狙天"玩法 |
| ☠️ 同时死亡 | 所有伤害在同一回合内同步结算，支持多人同时阵亡 |
| 🔄 房间持久化 | 游戏结束后可直接再来一局，无需重建房间 |

## 🚀 快速开始

### 环境要求

- [Node.js](https://nodejs.org/) >= 16.x

### 安装与运行

```bash
# 克隆项目
git clone https://github.com/你的用户名/fupai-game.git
cd fupai-game

# 安装依赖
npm install

# 启动服务器
node server.js
```

启动成功后访问 `http://localhost:3000`

### 局域网联机

查看本机局域网 IP，让同一 Wi-Fi 下的朋友用手机浏览器访问 `http://你的IP:3000`：

```bash
# Windows
ipconfig

# Mac / Linux
ifconfig
```

### 远程联机

**方式一：ngrok（临时测试）**

```bash
ngrok http 3000
```

将生成的公网链接（如 `https://xxxx.ngrok-free.app`）分享给朋友。

**方式二：部署到云服务器（推荐长期使用）**

将项目部署到 Render、Railway、Vercel 或自己的云服务器，详见 [部署指南](#部署)。

## ⚔️ 伤害计算公式

```
受到的伤害 = 伤害 - 防御力 + 类型系数（远程打近战 +0.5）
若结果 ≤ 0，则视为 0
```

## 📦 部署

### Render（免费）

1. 将代码推送到 GitHub
2. 在 [Render](https://render.com) 创建 Web Service，关联仓库
3. Build Command：`npm install`
4. Start Command：`node server.js`
5. 部署完成后获得公网域名

### Railway

1. 在 [Railway](https://railway.app) 新建项目
2. 连接 GitHub 仓库
3. 自动生成公网域名

### 自有服务器

```bash
# 安装 PM2 保持后台运行
npm install -g pm2
pm2 start server.js --name fupai-game
pm2 save
```
